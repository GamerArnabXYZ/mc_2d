# Fonts

Place a `font.ttf` here for HUD text rendering (FPS counter, item counts etc).

Recommended free fonts:
- **Press Start 2P** (pixel art style) — https://fonts.google.com/specimen/Press+Start+2P
- **Inconsolata** — https://fonts.google.com/specimen/Inconsolata

If `font.ttf` is absent, the renderer falls back to colored rectangles for text.
The game is fully playable without a font file.
